## Make Philosophy — Controlling Directives

### Core rule
Make should DESIGN first, not code Figma Design boards. Figma Design work established direction for Make to enhance, NOT for Make to recreate. Make-generated code is disposable prototype machinery, not runtime handoff.

### Prohibited Make behaviors
- Do not run Porcelain, Atmospheric, and Frost as Make themes — they remain diagnostic foundation packages
- Do not ask Make to explore new typography or spacing systems — it must compose the accepted laws
- Do not make Make responsible for callbacks, APIs, inventory, cart, payment, telemetry, or responsive production code
- Dark mode and broad inverse sections remain out of scope
- "Zero grey" means no generic achromatic/Tailwind grey leakage — approved blue-shifted neutrals remain valid

### Make handoff boundary
- **Fixed:** Plus Jakarta Sans display, Inter support, Inter-only purchase, #0057FF cobalt, exact product truth, 15-16px body min, 12px metadata min, 14-18px card radii, 8px chip radii
- **May decide:** Composition within laws, responsive ordering, chamber scale, canvas-split vs embedded-divider, local state transitions, trust-strip placement
- **May not decide:** Token names/publication, product claims, runtime data, APIs, React architecture, dark mode, new component anatomy, loading/error infrastructure, release readiness
