## What V4 supersedes

V4 supersedes the old Homepage-first M0 and the old Homepage → Site → Product → Checkout → OpenLab sequence. The Runtime Atlas is now complete, so Make should solve shared visual language before it assembles routes.

Do not use isolated renderless hero frames as primary Make context. Use native Runtime Atlas frames for current runtime truth and attach only the target surface’s six cells plus a small cross-route comparison set. Do not attach all 216 frames to one project.

The observed Baseline records useful token, type and pattern facts, but it is not an accepted visual direction. The overuse of primary text, grey enclosure, forced-dark route overrides, nested boxes and inconsistent route personalities are defects for Make to solve.
