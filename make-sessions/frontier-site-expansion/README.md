# OLUK Frontier Make Kit

**Status:** Prompt and baseline kit for private design exploration. It is not a Figma publication packet, runtime implementation, or production authority.

## Purpose

This kit turns the Sites frontier into four bounded design explorations:

1. OpenLab Portal and evidence modules.
2. PDP decision and continuation modules.
3. Checkout lifecycle and payment-trust hierarchy.
4. Commerce growth, account, stack, bundle and restock modules.

The runtime Sites implementation remains the source of component contracts, tokens, route namespaces, actual product renders and review coverage. Make may explore hierarchy, progressive disclosure, mobile compactness and editorial pacing; it must not replace product renders with generic supplements or invent a second visual language.

## Exact input discipline

- Start from `app.tsx` as a static creative baseline.
- Use only product assets listed in `assets.json`.
- Preserve `/product/:slug` and `/open-lab` route language.
- Preserve `MK-2866 · 15 MG · 90 SERVINGS · >99% · £43 · SKU 80529-01`.
- Preserve `RAD-140 · 8 MG`; do not use 10 MG in any generated screen or copy.
- Light mode only. The dark footer is the only inverse surface in the active system.
- Use Plus Jakarta Sans for display and Inter Variable for UI/body. Use the existing luminous blue canvas, white planes, graduated blue borders and cobalt as an action/relationship accent.
- Do not create payment forms, checkout calls, API clients, analytics, authentication, customer account mutations or fictitious source documents.

## Make output convention

Generate one desktop frame and one compact 390px frame per prompt. Show the mobile decision hierarchy deliberately: reorder, disclose, summarize, carousel or authorized horizontal scroll—never merely narrow the desktop layout.

## Handoff sequence

1. Run one prompt at a time.
2. Bring only selected outputs back as a review reference.
3. Record accepted relationships in the Review Studio/Figma intent registry.
4. Codex Sites implements or corrects the canonical module before a Figma component is backfilled.
