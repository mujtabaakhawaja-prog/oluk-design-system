# Run Procedure — Canonical Your Stack Frontier

## Preflight

1. Confirm the Make session is new and empty.
2. Confirm the active task is `FRONTIER-EXPANSION-01-CANONICAL-YOUR-STACK`, not MF-01.
3. Preview `reference-desktop.png` and `reference-mobile.png` locally.
4. Confirm the five attachment filenames and hashes from `product-data.json`/`BULK-RUN-MANIFEST.json`.
5. Confirm the variant lock before sending: Vertical desktop, optional single Featured promotion, Compact mobile, Relation only for a genuine horizontal micro-context.

## Execute

1. Paste `PROMPT.md` as one complete prompt.
2. Attach the five files listed in `MANIFEST.md`.
3. Verify all five attachments are visible before sending.
4. Send once.
5. Allow Make to finish all three directions; do not steer it into polishing the first direction early.

## Review

Review relationships rather than generated code:

1. chamber-to-content connection;
2. product prominence and selected state;
3. metric/status/action hierarchy;
4. mobile one-decision-at-a-time behavior;
5. cross-mount usefulness on PDP, Bag, Confirmation and Account.

Reject any direction that redraws generic product cards, substitutes a bottle, uses a cobalt outer outline, turns mobile into a long stacked desktop page, or exposes internal labels.

Also reject any direction that calls a locally assembled card "Vertical" or "Compact" while breaking the canonical chamber, metric, status, price, or action hierarchy.

## Handoff

Record the selected relationship and rejected traits. Codex then rebuilds only the selected relationship through the canonical Sites graph and refreshes the Growth module Review Studio decision. Make code is not copied.
