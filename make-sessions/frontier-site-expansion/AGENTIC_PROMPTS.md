# Agentic Implementation Prompts — Selected Make Relationships

These prompts are for rebuilding selected Make relationships in the Sites candidate. Make code is never copied into runtime. Every implementation begins with canonical provenance, governed styling, registered product media and compact responsive composition.

## Universal implementation preamble

Work in `sites/oluk-experience-lab` on the existing cumulative branch. Read `authority/ids-plan.md`, `authority/surface-contract.md`, `authority/SITE-ROUTE-LEDGER.json`, `authority/FRONTIER-SECTION-MOUNT-REGISTRY.json`, `authority/FIGMA-INTENT-REGISTRY.json`, `authority/PROGRAM-COMPONENT-REGISTRY.json` and the selected Make relationship receipt.

Before writing a component, identify its registered canonical source and all consuming routes. Import or extend that source. Do not build a route-local visual substitute. Use `actualProductMedia`/`productMediaRegistry` for imagery. A missing render produces an intentionally empty governed chamber; it never authorizes a generic bottle.

2. tokens/material/type/layout;
3. product-render binding;
4. 1440 and 390 composition;
5. cross-mount integration;
6. editorial polish;
7. tests and Review Studio payload.
