## Verdict

There is no whole-run champion.

The usable system is a deliberate synthesis:

- Run 1 A01 supplies the porcelain/ruled editorial grammar.
- Run 1 A02 supplies the pale cobalt field and white-island macro grammar.
- Run 1 A03 supplies the dense evidence/measurement grammar.
- Run 2 supplies responsive and state-proof lessons, not a sufficiently distinct creative direction.

The former “build from A02” decision is therefore replaced with:

> Porcelain field · Cobalt atmosphere · Ruled evidence.

This is a system thesis, not an instruction to copy any one frame.

## 3. Run 1 evaluation

### A01 — Porcelain Ruled

Node: `439:80259`

#### Transfer

- Strongest editorial section hierarchy.
- White-dominant restraint.
- Clear ruled boundaries and section-index logic.
- Useful 57/43 hero split.
- NarrativeRail + OperationalPanel reads as a reusable composition family.
- Assurance is correctly understood as a shared horizontal grammar rather than four unrelated feature cards.

#### Do not transfer

- Added serif typography is not automatically approved.
- Product media remains a small placeholder rather than a governed studio-render study.
- Product cards remain too slight and diagrammatic.
- Pure-white continuity alone cannot solve the current flatness problem.

#### Disposition

`DIRECTIONAL_DONOR` — editorial and ruled hierarchy.

### A02 — Cobalt Atmospheric

Node: `439:81059`

#### Transfer

- “The field is the divider” is the strongest macro-system move across both runs.
- Pale cobalt establishes context without turning saturated blue into decoration.
- Opaque white islands create useful depth without shadow.
- The commerce-to-evidence transition is structurally legible.
- The field/island language can span hero, product, assurance, and evidence surfaces.

#### Do not transfer

- It does not resolve the product-card primitive.
- The product media remains generic and underscaled.
- Repeating atmospheric fields mechanically would become a stripe system.
- A02 is a macro grammar, not a component contract or whole-system champion.

#### Disposition

`DIRECTIONAL_DONOR` — field/island and macro transition grammar.

### A03 — Instrumental Split

Node: `439:81857`

#### Transfer

- Strongest evidence density and measurement cadence.
- Clear distinction between narrative context and operational record.
- Useful proportion shift at the commerce/evidence threshold.
- Technical type treatment works for tables, metrics, methods, and state annotation.

#### Do not transfer

- Too severe and instrument-like for universal commerce.
- The §-index system should not become a brand-wide decorative device.
- Dense mono treatment is appropriate to evidence, not every customer surface.
- Conversion hierarchy is weaker than A01/A02.

#### Disposition

`DIRECTIONAL_DONOR` — EvidenceDistrict and measurement grammar only.

### Comparison and recommendation boards

Nodes: `439:82621`, `439:83966`

Run 1’s comparison board gives A01 49/55 and the recommendation frame promotes A01. That self-assessment is useful as rationale evidence, not promotion authority.

It is superseded because:

- its criteria are equally weighted without human approval;
- it overweights immediate implementation plausibility;
- it evaluates directions as indivisible wholes;
- it cannot detect that the stronger system is a donor synthesis.

Disposition: `HISTORICAL_SELF_ASSESSMENT`.

## 4. Run 2 evaluation

Nodes: `439:84332`, `439:85808`, `439:87376`

### What Run 2 proves

- Desktop, tablet, and mobile reflow can be shown in one artifact.
- The desktop specimen is a 1171 px content-canvas representation labeled for a 1440 viewport, not literal 1440 px viewport proof.
- State and control bands need explicit specimens.
- The system must be tested in consecutive route context, not only isolated diagrams.
- Product, assurance, evidence, and email modules can coexist within one light route.

### Why it is not the creative foundation

- All three directions reuse essentially the same page topology.
- Product cards remain generic stacked commerce tiles.
- Product media is visually small and does not establish scale.
- Repeated saturated-blue pill CTAs flatten hierarchy.
- Rounded containers are overused.
- Each direction contains a shadow despite the zero-shadow light law.
- Metric, price, and action relationships remain unresolved.
- Responsive proof occurs before the primitives are strong enough to deserve propagation.

### Direction-specific notes

| Direction | Useful move | Limitation |
|---|---|---|
| Run 2 A01 | Cleanest white/ruled route | Most generic and least atmospheric |
| Run 2 A02 | Best pale-field continuity | Still the same card and route skeleton |
| Run 2 A03 | Strongest technical section markers | Instrumental styling does not materially change the component system |

Disposition for all three: `RESPONSIVE_PROOF_DONOR`, not creative champion.

## 5. What neither run resolves

1. Product-card hierarchy across Grid, Featured, and QuickAdd.
2. A media chamber that establishes real bottle scale.
3. A two-cell Grid MetricRail using Strength + Servings without converting servings into capsule count.
4. Price that remains visible but subordinate.
5. CTA geometry that is decisive without becoming a repeated blue pill.
6. The shared AssuranceRail.
7. The DossierRail.
8. A source-safe PurchasePanel without unsupported benefit claims.
9. A fully proven commerce-to-evidence threshold using real record data.
10. Correct shell/navigation authority.
11. A human-reviewed component and viewport adoption path.
