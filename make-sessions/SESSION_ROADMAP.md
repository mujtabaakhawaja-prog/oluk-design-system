## Make operating sequence inside each run

1. Design static customer-facing compositions first.
2. Compare three materially different relationships.
3. Human selects the strongest relationships.
4. Refine the selected direction in route context.
5. Add selected native nodes only after the visual direction is established.
6. Prove real 1440, 768 and 390 recomposition.
7. Add local visual interaction only after the static composition passes.
8. Record deviations and reusable structures; make no runtime claim.
