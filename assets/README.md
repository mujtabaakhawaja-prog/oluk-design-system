# Governed and Reference Assets

Repository presence does not equal Make attachment authority.

## Product render pack

[`product/mk-2866/render-alpha/`](product/mk-2866/render-alpha/) contains five transparent-front render sizes derived from the supplied approved MK-2866 source. Use the largest suitable source in native Figma or after MF-01 selection. Do not attach these separately to MF-01 because the sealed three PNGs already contain product imagery.

## Logo reference pack

[`brand/logo/reference/`](brand/logo/reference/) contains supplied horizontal lockup, slash-mark and presentation exports. They are registered as reference assets, not yet as a final logo master system with clear-space/minimum-size authority.

## Make run assets

The MF-01 attachment set lives with the run at [`../make-sessions/session-01-product-card/assets/`](../make-sessions/session-01-product-card/assets/). Its manifest—not this directory—controls the opening upload.

Use [`CHECKSUMS.sha256`](CHECKSUMS.sha256) to verify the governed render and supplied logo-reference files after download.
