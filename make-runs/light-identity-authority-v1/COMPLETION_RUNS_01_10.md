# Completion Runs 01–10

## Operating rule

Run the foundation `PROMPT.md` first and pass `REVIEW_GATE.md`.

Run packets 01–08 sequentially in the same accepted Make project. Duplicate or
version the project immediately before each run. Do not attach new aesthetic
references unless a packet explicitly names one. The locked light identity is
the authority; each run completes a page family instead of rediscovering it.

Packets 09–10 move out of creative Make work. Packet 09 is browser QA and
capture. Packet 10 is native Figma adoption plus the Codex implementation
handoff.

Dark mode is out of scope for all ten packets.
